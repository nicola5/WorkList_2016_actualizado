# WorkList

Aplicación web de lista de tareas (to-do list) construida con **AngularJS**.

## Tecnologías
- AngularJS
- Bower (gestor de dependencias del frontend)
- HTML / CSS / JavaScript

## Estructura
```
public/
  index.html          # Punto de entrada
  app/
    app.js             # Módulo principal de Angular
    main/
      main.js           # Definición de rutas/controlador principal
      main_controller.js # Lógica del controlador
  lib/                  # Dependencias (Angular, etc.)
```

## Cómo correrlo
Requiere un servidor estático simple (por ejemplo `http-server` o Live Server) apuntando a la carpeta `public/`.

## Contexto
Proyecto personal de 2016, usaba [Floobits](https://floobits.com/) para edición colaborativa en tiempo real.
